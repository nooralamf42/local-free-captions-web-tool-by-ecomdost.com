# Fonts

All fonts here are open-source (SIL Open Font License 1.1 or Apache 2.0) and come from Google Fonts or their authors' repositories:

Abril Fatface, Anton, Archivo Black, BBH Bartle, Bagel Fat One, Baloo 2, Bangers, Bebas Neue, Black Han Sans, Black Ops One, Bowlby One, Bungee, Caprasimo, Caveat,
DM Serif Display, Dancing Script, Fredoka, Gloock, Gloria Hallelujah, Great Vibes, Instrument Sans, Instrument Serif, Inter, Jost, Kaushan Script, Lilita One, Limelight,
Lobster, Luckiest Guy, Mona Sans, Monoton, Montserrat, Mynerve, Open Sans, Pacifico, Permanent Marker, Pinyon Script, Playfair Display, Poppins, Press Start 2P, Righteous,
Rubik, Rubik Mono One, Rubik Spray Paint, Shadows Into Light Two, Shrikhand, Silkscreen, Special Elite, Staatliches, Unna, Yellowtail, Yeseva One.

Each font stays under its own licence (see its page on <https://fonts.google.com>). Some files are static instances cut from the variable fonts
(Mona Sans, Open Sans, Playfair Display, Jost, Rubik Black), which the OFL allows. The fonts are used by the video renderer (ffmpeg / libass) and the browser preview.

To add a font: copy the `.ttf` here (open licences only), then use its family name in a template. Do not add commercial fonts.
